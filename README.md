📱 О приложении
QuickNote - это удобное мобильное приложение для создания и управления заметками, дополненное прогнозом погоды и вдохновляющими цитатами. Все данные сохраняются локально на устройстве.

✨ Основные функции
📝 Умные заметки
Создание, редактирование и удаление заметок

Автоматическое сохранение при каждом изменении

Локальное хранение (работает без интернета)

Экспорт заметок в текстовый формат

Интуитивный интерфейс редактирования

🌤️ Погода в реальном времени
Текущая погода для любого города мира

Детальная информация:

Температура (ощущаемая и реальная)

Влажность и давление

Скорость ветра

Восход и закат солнца

Видимость

Кэширование данных на 10 минут

Автоматическое определение города (Вологда по умолчанию)

💬 Цитата дня
Ежедневные вдохновляющие цитаты

Автоматическое обновление

Сохранение понравившихся цитат

Информация об авторе

Используемые технологии
Flutter/Dart - кроссплатформенная разработка

Provider - state management

SharedPreferences - локальное хранилище

HTTP - работа с внешними API

OpenWeatherMap API - данные о погоде

Quotable API - цитаты
